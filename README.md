# IIM Technical Services: website

A rebuild of www.iimtechnicalservices.com with Next.js (App Router, TypeScript), Tailwind CSS locked to design tokens, and Sanity CMS. It is hosted on Hostinger (Node.js) behind Cloudflare.

The project brief and working rules are in [CLAUDE.md](CLAUDE.md). The project is in **Phase 0 (plan)**; no application code yet.
